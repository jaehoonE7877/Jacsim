# Walkthrough Page Overrides

> Applies to: `Projects/Jacsim/Sources/Presentation/WalkThorugh/WalkThroughView.swift`

## Layout Overrides

- 상단 bar + 페이지 콘텐츠 + 하단 CTA 구조
- 페이지 인디케이터는 현재 단계 인지가 명확해야 함

## State Policy

- 알림 권한 거부 시 복구 안내 텍스트 노출
- 마지막 페이지 CTA는 시작 행동으로 명확히 전환

## Accessibility Notes

- 건너뛰기/계속하기 버튼의 라벨이 단계 맥락을 설명해야 함
